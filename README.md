# AUTO CHOICE

**«Какой способ покупки автомобиля вам подходит?»** — локальный интерактивный тест.

Это не магазин и не реклама. Человек отвечает на 7 вопросов, а приложение
по простой системе баллов показывает, какой сценарий покупки выглядит
рациональнее:

1. автомобиль под заказ;
2. стоит сравнить оба варианта;
3. автомобиль в наличии.

Приложение работает только на вашем компьютере: оно ничего не отправляет
в интернет и не спрашивает имя, телефон или почту.

## Какие файлы за что отвечают

| Файл | Что делает |
| --- | --- |
| `app.py` | Flask-приложение: страницы «старт → вопросы → результат» |
| `quiz_data.py` | Вопросы, варианты ответов, баллы, факторы-пояснения, пороги и тексты результатов |
| `scoring.py` | Подсчёт баллов, выбор результата и подбор факторов-пояснений (логика теста) |
| `branding.py` | Название бренда и подпись в подвале |
| `requirements.txt` | Список зависимостей (только Flask) |
| `templates/` | HTML-страницы: `base.html`, `index.html`, `question.html`, `result.html` |
| `static/css/style.css` | Оформление (цвета, шрифты, адаптация под телефон) |
| `static/js/main.js` | Минимальный JavaScript: сообщение кнопки «Обсудить мой случай» |

**Как менять тест:** вопросы, баллы и тексты результатов правятся в `quiz_data.py`,
правила подсчёта — в `scoring.py`. Интерфейс при этом трогать не нужно.

**Откуда берутся пояснения на странице результата:** у каждого варианта ответа
в `quiz_data.py` есть поле `factor` — короткое пояснение, и поле `group` —
его смысловая категория (например, `speed`, `waiting`, `personal_inspection`).
После теста показываются до 3 факторов из реальных ответов человека:
для «под заказ» — ответы с наибольшими баллами, для «в наличии» — с наименьшими,
для «сравнить оба» — аргументы обеих сторон по очереди. Две причины из одной
категории не показываются, чтобы мысли не повторялись; если разных причин
меньше трёх, выводится сколько есть. Баллы и категории на странице
не показываются.

## Как установить зависимости

Нужен Python 3.10 или новее. В папке проекта выполните один раз:

```
pip install -r requirements.txt
```

## Как запустить приложение

В папке проекта выполните:

```
python app.py
```

## По какому адресу открыть сайт

Откройте в браузере:

```
http://127.0.0.1:5000
```

Остановить приложение: в окне терминала нажать `Ctrl + C`.
